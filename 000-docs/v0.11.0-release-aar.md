## The notable lesson — a premise finding re-scoped a bead

`ccsc-z0n.2` was written as "inject placeholders, swap the real value at the boundary" (the peer runtime's pattern). Investigation before coding showed the premise didn't hold for CCSC: the Claude session **spawns the bridge as a separate MCP-stdio subprocess**, so the tokens live only in the bridge process and flow only into Slack-bound sinks — the agent never holds the value, and a placeholder-*injection* layer would be redundant. The bead was re-scoped to (a) a runtime defense-in-depth scrub and (b) a `THREAT-MODEL.md` T4 note documenting the structural guarantee. The finding was recorded on the bead trail (and GH #209) **before** a line was written — the readable-trail rule working as intended. Lesson: validate a borrowed pattern's premise against your own architecture before implementing it.
